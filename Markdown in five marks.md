# Markdown in five marks

If the word markdown makes you think this is for technical people, here is the
entire thing on one page.

Markdown is ordinary writing plus about five small marks. You write normally.
Occasionally you add a character. That is it.

## The five

| Mark | You type | You get | Say it out loud as |
|---|---|---|---|
| Hash | `# A heading` | a heading | a heading |
| Two stars | `**important**` | **important** | bold |
| Dash | `- a thing` | a bullet in a list | a list |
| Two square brackets | `[[Another note]]` | a link to another note | a link |
| Backticks | `` `left alone` `` | `left alone` | code |

## A worked example

This, typed exactly as it looks:

```
# Why the meeting worked

**We asked before we told.**

- Nobody was presented at
- Everyone had to say one thing
- We stopped at fifty minutes

Next: [[Things that landed]]
```

comes out as a note with a heading, one bold line, a three item list, and a
working link. Five marks, all five used, nothing else needed.

## The things worth knowing after that

- **The hash scales.** One `#` is the biggest heading, `##` is the next one
  down, `###` below that. That is the only variation you will use for months.
- **The link is the powerful one.** `[[ ]]` is what makes this a brain rather
  than a drawer. Write a link to a note that does not exist yet, then click it,
  and it gets made for you.
- **You will forget the marks and it will not matter.** Obsidian shows you the
  formatted version as you type, so you get told immediately when you get it
  right.
- **It is not a format you can be trapped in.** A markdown file is a text file.
  Open it in anything.

## What you can safely ignore

Tables, footnotes, images, checkboxes, callouts and about thirty other things
all exist. None of them are needed to start, and reaching for them early is one
of the ways people talk themselves out of writing the note.

Five marks. Then write.
