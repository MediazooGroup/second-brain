# Skills

A skill is a repeatable instruction you hand to an AI assistant: a job you redo every week, written down once as a `SKILL.md` file the assistant can read and follow. You keep the decision; it does the typing.

## The two skills from part 3

These are the actual skills used live on *The Second Brain Blueprint*, part 3. Each is a single `SKILL.md` - just markdown, open it and read it.

| Skill | What it does |
|---|---|
| [[second-brain-builder/SKILL\|second-brain-builder]] | Builds a new second brain from a folder of sources. It shows you the plan first and writes nothing until you type `APPROVE BUILD`. |
| [[second-brain-updater/SKILL\|second-brain-updater]] | Files new material from the inbox into the right pages. It proposes changes in a report, waits, and applies them only when you type `APPROVE UPDATE`. Your source files never change. |

## How to use them

1. Open the skill's `SKILL.md` and read it. That is the whole skill.
2. Add it to your assistant - Claude (as a skill or project instructions), Copilot, ChatGPT or any tool that accepts instructions. It is just markdown; paste it or upload it.
3. Point the assistant at a folder of your own material and ask, in plain words, for a build or an update.
4. Read what it proposes before you approve. That habit is the whole method.
