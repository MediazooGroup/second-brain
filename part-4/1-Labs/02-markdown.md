# Markdown, the container

![[1-Labs/images/02-markdown.png]]

Your organisation's knowledge is trapped. It is inside decks, inside PDFs, inside a wiki nobody can export, inside an app that will be replaced in three years. When you want to hand all of it to an assistant, you cannot — because none of it is readable as text.

Markdown is the way out, and it is smaller than you think. A text file, with a handful of marks in it.

- `#` for a heading
- `-` for a bullet
- `**bold**` for bold
- `[[square brackets]]` to link one file to another

That is most of it. If you can write a checklist for a colleague, you already know markdown.

Why it matters at organisational scale is not elegance. It is these four:

**It is plain text.** No licence, no export, no migration project. Open it in anything, forever.

**A machine reads it perfectly.** Headings tell the assistant what a section is. Front matter at the top of a file tells it what the file is.

**It diffs.** You can see exactly what changed in a document, and when. Try that with a deck.

**It links.** One note points at another, and a body of knowledge becomes a network rather than a pile.

Part two, if you want the ground-up version: `https://www.youtube.com/watch?v=olvJH--I0T0`

**Everything you will see today — three brains, seventy-odd pages — is nothing but these files.** No database. No platform. No subscription.
